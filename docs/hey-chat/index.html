Hey Chat
Transcript Backup

Keep a private copy of locally recognised speech, with an optional backup in your own Google Drive.

Microphone → local speech recognition → local transcript → your Google Drive

What the tool does

Hey Chat listens for configured voice phrases on a Mac. Speech recognition runs locally. If transcript saving is enabled, it saves corrected text and approximate phrase timestamps on that Mac.

The optional backup job uploads a compact JSON snapshot for each changed day to the connected Google account. It runs daily while the Mac is on external power. Unchanged transcripts are not uploaded again, and earlier cloud copies are retained.

Google Drive access

The backup asks for access only to files created or explicitly opened with this app. It does not request access to the rest of your Drive. Audio recordings and Google credentials are not included in the transcript backup.

Your controls

You can turn listening and transcript saving off independently, delete saved copies, or revoke the Google connection. Turning saving off does not delete existing transcripts or backups.

This is Ethan’s personal utility. This page describes the tool and its Google connection; it is not a public download or hosted transcription service.
