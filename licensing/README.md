# Shared source licence for selected personal apps

`NO-SALE-TERMS.txt` is the canonical text of Ethan Source-Available No-Sale Terms 1.0. Released versions are immutable. Copy it byte-for-byte into an eligible repository, document that repository’s ownership and exceptions in `LICENSING.md`, preserve previous grants and third-party notices, and update package metadata and current-source claims together. A new set of terms requires a new version and an explicit rights check.

The PolyForm base was drafted by licensing lawyers; the project-specific additions still need review by counsel for the intended business. No license text establishes ownership or revokes earlier permissions.

## Scope

These terms are for Ethan’s selected modern, purely vibe-coded personal apps that he uses and publishes, in the same small scope retained for project user preferences, and future projects of that kind. They are not a default for every public or Ethan-owned repository. Private projects, AIMVS and its dev skill, old coursework, legacy experiments and unrelated repositories are excluded. Each covered repository’s `LICENSING.md` states its actual owned-code scope and exceptions; public visibility alone does not establish eligibility.

This repository stores the shared terms for those apps; Ethan’s setup website itself retains its MIT licence and the separate asset exclusions in its README. People may use the covered apps themselves; selling the covered software, modified versions or paid access requires Ethan’s separate permission. Prior grants and other contributors’ rights remain in force.
