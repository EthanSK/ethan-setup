# Licensing selected personal apps

## Current published terms

For eligible apps, use **Apache License 2.0 with Commons Clause License Condition v1.0**.
The legal sources are [Apache's official text](https://www.apache.org/licenses/LICENSE-2.0.txt)
and [Commons Clause's official text](https://commonsclause.com/).
Local reference copies are [APACHE-2.0.txt](APACHE-2.0.txt) and
[COMMONS-CLAUSE-1.0.txt](COMMONS-CLAUSE-1.0.txt).

Create an app's `LICENSE` by completing only the Commons Clause `Software`,
`License` (`Apache License 2.0`) and `Licensor` fields, followed by the full
Apache text verbatim. Keep the published legal wording unchanged. Include the
combined licence notice wherever the underlying licence requires attribution.
Use `SEE LICENSE IN LICENSE` for package metadata, not plain `Apache-2.0`.

You may use and modify the covered software, including internally at work,
and redistribute it under the combined terms. Commons Clause restricts selling
a product or service whose value derives entirely or substantially from the
software's functionality. It does not prohibit every commercial use or every
paid product that uses the code. This combination is source-available, not
OSI-approved open source. The actual legal terms govern.

## Scope

This policy is for Ethan's selected modern, purely vibe-coded personal apps
that he uses and publishes, in the same small scope retained for project user
preferences, and future projects of that kind. It is not a default for every
public or Ethan-owned repository. Private projects, AIMVS and its dev skill,
old coursework, legacy experiments and unrelated repositories are excluded.
Each covered repository's `LICENSING.md` states its actual owned-code scope
and exceptions; public visibility alone does not establish eligibility.

This repository stores the shared reference texts. Ethan's setup website uses
the project-specific custom offer below for covered first-party material, with
the separate asset exclusions in README.md and LICENSING.md.
No licence text establishes ownership or revokes valid earlier permissions.
Preserve third-party terms, contributor rights and earlier grants. Keep root
and packaged-component licence copies, README, package metadata and public
current-source notices consistent. Previously released binaries retain the
terms supplied with those releases; include the current combined terms and
required third-party notices in the next release.

## Project-specific custom offer

[NO-SALE-TERMS.txt](NO-SALE-TERMS.txt) contains Ethan Source-Available No-Sale
Terms 1.0. It is the current offer for covered first-party material in these
four projects only:

- Magic Wand
- Agentic DJ
- Response Preferences
- Ethan's setup website

Other eligible apps keep Apache License 2.0 with Commons Clause as described
above. This exception does not change their terms or the default for future
eligible apps. Each repository's LICENSE and LICENSING.md define its actual
terms and exclusions. Earlier grants and third-party rights remain in force;
changing licence text or Git history does not withdraw them.
